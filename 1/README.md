# Лабораторная работа 1 — вариант 10

**Тема:** вещественный генетический алгоритм для минимизации функции Михалевича.
Вариант вычислен по методичке для `N=8`, группы `517` (`Q=1`) и `Y=26`:
`V = 1 + ((17·8 + 7·1 + 26) mod 20) = 10`. Размерность `d = 5 + (V mod 6) = 9`.

## Установка и запуск

Нужен Python 3.10+; внешние пакеты не используются.

```powershell
python .\ga.py
```

Для ускорения/воспроизводимости можно задать все параметры явно:

```powershell
python .\ga.py --runs 20 --seed 2026 --population 100 --generations 250 --workers 2
```

Для каждой конфигурации выполняется 20 независимых запусков. Вариант GA отличается
только вероятностью мутации (`0.10` или `0.25`); случайный поиск получает тот же
бюджет оценок фитнес-функции. `--workers 1` отключает многопроцессное оценивание.

Скрипт сохраняет `results.csv` (все запуски), `metrics.json` (сводная статистика и
лучшие решения), `convergence.csv`, `convergence.svg` и интерактивную
`demo_2d.html` для демонстрации сходимости при `d=2`. HTML-файл откройте в браузере;
ползунок переключает поколение.

Тесты запускаются командой `python -m unittest -v`.

## Модель

Минимизируется

`f(x) = -Σ(i=1..d) sin(x_i) · sin(i·x_i²/π)^(2m)`,

где `m=10`, `x_i ∈ [0, π]`, `d=9`. Так как функция сепарабельна, независимая
минимизация каждого слагаемого даёт численный ориентир около `-8.660152` для этой
размерности; это цель для сравнения, а не гарантия эвристики.

Особи — вещественные векторы. Используются турнирная селекция, BLX-α (`α=0.5`),
гауссова мутация с адаптивно уменьшаемым масштабом, отсечение координат по границам
и элитизм двух лучших особей.
Фитнес независимых особей оценивается через `ProcessPoolExecutor`.

Масштаб гауссовой мутации адаптивно уменьшается от `0.12·π` до `0.006·π` по мере
роста поколения: в начале поиск исследует область, ближе к остановке — уточняет
решения. Реализация следует лекционным записям: популяционный поиск, оценка качества,
селекция, рекомбинация, мутация и воспроизводимый эксперимент с разными seed.
Формула, вариант и обязательные эксперименты взяты из методички лабораторных работ.
