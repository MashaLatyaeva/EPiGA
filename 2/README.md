# Лабораторная работа 2 — вариант 10

**Тема:** генетический алгоритм для недельного плана дежурств с ограничениями.
При `N=8`, группе `517` (`Q=1`) и `Y=26` методичка даёт `V=10`.

## Установка и запуск

Python 3.10+; зависимости не требуются.

```powershell
python .\schedule.py
```

Для воспроизводимого повторного запуска:

```powershell
python .\schedule.py --runs 20 --seed 2026 --population 60 --generations 80
```

При первом запуске формируется `data.json`: 10 сотрудников, 21 событие (три смены
в день в течение недели) и 27 пар несовместимых смен. Предпочтения синтетические,
сгенерированы seed `2026`. Сохраняются `results.csv`, `metrics.json`,
`best_schedules.csv` и `convergence.svg`. Проверка ограничений и операторов:
`python -m unittest -v`.

## Представление и ограничения

Особь — целочисленный вектор из 21 назначения: ген `i` указывает номер сотрудника,
назначенного на смену `i`. Равномерный кроссовер комбинирует назначения; сравниваются
две специализированные для вектора назначений мутации: переназначение смены и обмен
назначениями двух смен.

Жёсткие ограничения: каждая смена укомплектована; сотрудник не назначается на
конфликтующие смены (все пары смен одного дня и ночь → утро следующего дня);
не более четырёх дежурств в неделю. Сравниваются два способа обработки ограничений:
ремонт потомка до допустимого расписания и штраф `1000` за каждое нарушение.
В обеих конфигурациях оптимизируются предпочтения сотрудников и равномерность
нагрузки: стоимость предпочтений плюс `2·Σ(load−2.1)²` и
`1.5·Σ(night−0.7)²`. Сравнение с конструктивным случайным поиском использует тот же
бюджет кандидатов, причём каждый кандидат восстанавливается до допустимого.
